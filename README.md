# Ops Dashboard (CutFlow)

Cloud cut-sheet organizer for Drawer Box Specialties.

- Split Top/Parts/Bottom by **ship-date paper color** (Mon Purple → Fri Red)
- Group Top+Parts by **material family** (Ply → Solid → MDF/PBC → FAA)
- Download print-ready PDFs per color
- Local M611 tray printing stays on the workstation CutFlow app

## Develop

```bash
npm install
npm run dev
```

## Deploy

Configured for Vercel project **ops-dashboard**.
